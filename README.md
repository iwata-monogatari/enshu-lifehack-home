# enshu-lifehack-home

遠州ライフハック 親サイト（`https://enshu-lifehack.com/`）。

- 遠州8市町の写真・地域モチーフのピクトグラム、公開中の懐かし写真館8館、富士ヶ丘サービスへの相談導線、大石浩之の活動と43サイトを案内するトップページ。
- Cloudflare Workers（Static Assets）。`www.enshu-lifehack.com` は `src/index.js` で apex へ 301。
- 静的ファイルは `public/`。

## デプロイ
```
wrangler deploy        # カスタムドメイン(enshu-lifehack.com / www)もこの設定で自動付与
```

## 市町を公開したら
`public/index.html` がトップページの原本。写真館は公開を確認できた市町だけにリンクを設ける。市町写真の出典・利用条件はページ末尾と `public/images/cities/credits.json` に保持する。CC BY-SAの写真の改変版も元と同じライセンスで扱う。

活動一覧は2026年11月21日時点の43サイト（本サイトを含む）。追加・変更時は本文一覧と `public/site-directory.json` の名称・URL・基準日をそろえる。学校紹介サイトは非公式であり、人物一覧の公開や学校の公認を示す紹介へ変更しない。

相談導線は無料実家カルテの申込み・見本、介護の見学相談、窓口別の電話へ接続。無料の条件・電話・受付時間は各運営サイトの現行案内を確認して更新し、既存の計測スクリプト・UTMを保持する。サイト閲覧やクリックを成約と扱わない。

運営：富士ヶ丘サービス ／ 代表：大石浩之

## 全体フィード `/feed.xml`（RSS 2.0）
- `public/feed.xml` は **生成物**。手で編集しない。`node scripts/build_feed.mjs` が各市町のブログ記事フィード（各サイトの記事台帳から生成）を集め、新しい順に最大40件を書き出す。
- `wrangler.toml` の `[build]` で deploy のたびに再生成。`.github/workflows/feed.yml` が毎日再生成し、変化があればコミットする。
- ブログを始めた市町は `scripts/build_feed.mjs` の `SOURCES` に1行足す。

## 重複掲載を避ける配置（2026-11-21）
市町ライフハックは市町カード、写真館は写真館欄に各1回掲載する。活動一覧・フッターに同じ一覧を再掲しない。相談欄にある不動産・新築住宅の紹介と、学び・文化欄にある暦の紹介も重複させない。ページ内ナビゲーション、申込み・見本など目的の異なる導線、写真出典・計測を保持する。43サイトはページ全体の案内先と本サイトを含む台帳の総数で、下部の活動一覧だけの件数ではない。
